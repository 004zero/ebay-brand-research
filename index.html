利益計算の前提

カテゴリ別 送料（円・日本→米国、梱包後の目安）

総合スコアの重み

実測データがある行だけスコアが付きます。売切率は出品中データがある場合のみ加味（ない場合は他の重みで按分）。

このツールでできること

  • ブランドごと・カテゴリ（バッグ／財布／小物…）ごと・全体で、どれがよく売れて回転が速いかをランキング表示
  • eBay の Sold（売れた商品）データを取り込み、30日の売れた数・1日あたり・売切率・在庫消化日数・中央値・価格帯分布を自動計算
  • タイトルから売れ筋モデル（Speedy／Neverfull／Marmont…）・ライン・色・サイズを自動抽出し、モデル別の中央値と仕入上限を表示
  • 為替・手数料・関税・送料・目標利益率から仕入上限（円）を逆算。メルカリ／ヤフオク／セカスト等への仕入検索リンク付き
実測データがないブランド×カテゴリは、内蔵の「需要★」と「価格帯目安」だけを表示します。あくまで目安なので、気になる組み合わせは必ず Sold を取り込んで実測してください。

手順

  1. 「データ取り込み」タブで ブックマークレットをブックマークバーへドラッグ（初回のみ）。
  2. ブランドとカテゴリを選び「Sold を開く」→ eBay の売れた商品一覧が開く（日本セラーのみ・売れた日が新しい順・240件表示）。
  3. そのページでブックマークレットをクリック。自動で次ページも集めてコピーされる（数秒〜20秒）。
  4. ツールに戻り、貼り付け → 解析 → ブランド・カテゴリを確認して保存。
  5. 同じ要領で「出品中を開く」→ ブックマークレット → 貼り付け（売切率・在庫消化日数に必要）。
  6. ランキングで比較 → 行をクリックして詳細分析 → 売れ筋モデルの仕入上限を見ながら仕入先リンクで探す。

スマホ（iOS Safari / Android Chrome）：ブックマークレットのリンクを長押し→「リンクをコピー」→任意のページをブックマーク→ブックマーク編集で URL を貼り替え。

指標の意味

30日の売れた数 / 1日あたり
取り込んだ Sold の「売れた日」から計算。取り込み件数が eBay の表示件数より少ない場合は、集めた期間から換算。
90日の売れた数
売れた日から数えた直近 90 日の実数。収集期間が 90 日に満たない場合は 1 日あたりから換算。
売切率
90日の売れた数 ÷（90日の売れた数＋現在の出品中数）。高いほど供給不足＝売れやすい。
在庫消化日数
現在の出品中数 ÷ 1日あたり売れた数。いま出品されている分が何日で捌けるか。少ないほど回転が速い。
日本セラー比率
売れた商品のうち発送元が Japan の割合。高いほど日本からの出品が受け入れられているジャンル。
仕入上限（円）
売れた中央値 × 為替 − 手数料 − 関税（セラー負担時）− 送料 − 梱包 − 目標利益。この金額以下で仕入れれば目標利益率を確保できる目安。
総合スコア / 判定
回転・売切率・単価・日本セラー比率・価格安定度を重み付けして 0〜100 点。S（75以上）A（60）B（45）C（30）D。

注意

  • eBay を日本から見ると価格が「JPY 34,924」のように円表示になることがあります。ブックマークレットは通貨を判定して自動でドルに換算します（設定の為替を使用）。もし取り込み済みデータの中央値が異常に大きい場合は、取り込みタブの「円→$換算」ボタンで直せます。
  • eBay のページ構造が変わると取り込めなくなることがあります。件数が 0 の場合はページを再読み込みして再実行してください。
  • eBay の Sold 一覧は「実際に売れた価格」ですが、値引き交渉（Best Offer）成立分は表示価格と異なる場合があります。
  • 高額ブランド品は eBay Authenticity Guarantee・偽物申告・返品リスクがあります。関税や返品分は設定で余裕を持たせてください。
