# ブランド品 eBay 売れ筋リサーチ（ebay-brand-research）

ブランド×カテゴリ（バッグ／財布／小物／時計…）ごとに、eBay で「よく売れて回転が速い」組み合わせと売れ筋モデル、仕入上限（円）を判定する静的ツールです。サーバー不要・API キー不要。

## 構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面（ランキング／詳細分析／データ取り込み／設定／使い方） |
| `app.js` | 集計ロジック・ブックマークレット・描画 |
| `data.js` | 内蔵データ（34 ブランド × 14 カテゴリの需要★と価格帯目安、モデル名辞書、仕入先リンク） |
| `起動.bat` | ローカル確認用（http://localhost:3320） |

## 使い方

1. 「データ取り込み」タブのブックマークレットをブックマークバーへドラッグ（初回のみ）。
2. ブランド・カテゴリを選び「Sold を開く」→ eBay の売れた商品一覧でブックマークレットを実行（Sold は最大 5 ページ自動収集）。
3. コピーされた JSON をツールに貼り付けて保存。「出品中を開く」も同様に取り込むと売切率・在庫消化日数が出ます。
4. ランキングで比較 → 行クリックで詳細分析（価格帯分布・売れ筋モデル・仕入上限・仕入先リンク）。

## 指標

- 30日の売れた数／1日あたり：Sold の「売れた日」から計算（売れた日が新しい順で収集する前提）。
- 90日の売れた数：eBay の Sold 表示件数（直近約 90 日）。
- 売切率 = 90日Sold ÷（90日Sold＋出品中数）。在庫消化日数 = 出品中数 ÷ 1日あたり。
- 仕入上限 = 中央値×為替 − 手数料 − 関税（セラー負担時）− 送料 − 梱包 − 目標利益。
- 総合スコア：回転 35／売切率 25／単価 15／日本セラー比率 15／価格安定度 10（設定で変更可）。

## データ

取り込みデータ・設定は localStorage（キー `ebr_v1`）に保存。JSON バックアップ／復元・ランキング CSV 出力あり。Terapeak 等の CSV（タイトル列・価格列が必要）も取り込み可能。
